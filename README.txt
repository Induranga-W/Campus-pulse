NSBM NewsDesk — Campus Pulse
============================
University news, events and student information website for NSBM Green University.

Module : Web and Mobile Application Development (Batch 26.1 IFSL)
Stack  : HTML5, CSS3, PHP (PDO), MySQL / MariaDB, vanilla JavaScript

Goal
  Students read campus news and events, register, submit stories and follow topics.
  Editors and admins review stories and manage the site from an admin panel.

Team (6 members)
  M1 Project lead and deployment   M2 Database
  M3 Login and security            M4 Public pages
  M5 Submissions and admin         M6 Interactions, design and testing

Work is delivered step by step through pull requests (one feature per pull request).
Full setup and hosting instructions are added in the final pull request.
